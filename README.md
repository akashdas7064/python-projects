# Simple Calculator (Python)

A simple and interactive command-line Calculator built with Python. This project performs basic arithmetic operations including addition, subtraction, multiplication, and division through a user-friendly menu-driven interface. It also includes input validation and handles division-by-zero errors gracefully, making it a great project for beginners learning Python.

## Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* ✅ Menu-driven interface
* ⚠️ Input validation using `try-except`
* 🚫 Division-by-zero error handling
* 🔁 Continuous execution until the user chooses to exit

## Technologies Used

* Python 3
* Functions
* Loops (`while`)
* Conditional Statements (`if-elif-else`)
* Exception Handling (`try-except`)
* User Input (`input()`)

## Learning Outcomes

This project helps beginners understand:

* How to create and call functions
* Working with user input
* Using loops and conditional statements
* Handling exceptions in Python
* Building an interactive command-line application

This project is perfect for Python beginners who want to strengthen their programming fundamentals by creating a practical and easy-to-use calculator application.
